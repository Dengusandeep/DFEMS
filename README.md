 Digital Forensic Evidence Management System (DFEMS)

---

 Project Overview

DFEMS is a secure web-based application designed to manage digital evidence in cybercrime investigations. It ensures evidence integrity using SHA-256 hashing, maintains chain of custody, and provides role-based access control for secure forensic workflows.

---

  Features

- 🔐 User Authentication (Admin & Investigator)
- 📁 Case Creation and Management
- 📂 Evidence Upload (Multiple Files)
- 🔑 SHA-256 Integrity Verification
- 📜 Chain of Custody Tracking
- ⚠️ Tamper Detection
- ⬇️ Evidence Download
- 📦 Full Case Download (ZIP)
- 📄 PDF Report Generation
- 💻 Cybersecurity-Themed UI
